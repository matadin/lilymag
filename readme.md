# LilyMaG — LilyPond Maker for Guitar

## What is LilyMaG?

**LilyMaG** stands for **Lily**Pond **Ma**ker for **G**uitar.

LilyMaG is a simple tool that helps guitarists create music notation using a virtual fretboard. By clicking on the fretboard, you can generate snippets of [LilyPond](https://lilypond.org/) code that can be copied into a LilyPond source file and used to produce guitar scores.

LilyPond is a powerful music engraving program that produces high-quality sheet music from text-based notation.

## What LilyMaG can (and cannot) do

LilyMaG is a note-entry aid, not a complete graphical score editor. Clicking notes on the fretboard does not automatically produce a finished score. You will need at least a basic understanding of LilyPond and its notation.

The advantage of this approach is flexibility. You can use LilyMaG to generate a quick, simple score and then refine it directly in LilyPond. You are not limited by LilyMaG's features, but only by what LilyPond can do and your knowledge of how to use it.

## Using LilyMaG online or offline

You can use LilyMaG directly in your web browser or download it and run it locally, without an internet connection.

The application consists of just three files:

- `index.html` — the main application page
- `lilymag.css` — the visual styling
- `lilymag.js` — the application logic

Help files are in `help` folder. They are optional.

To use LilyMaG offline, download the files into the same folder on your computer and double-click `index.html` to open it in your browser. No installation is required.
