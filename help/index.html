LilyMaG Help

LilyPond Maker for Guitar

What is LilyMaG?

LilyMaG stands for LilyPond Maker for Guitar.

LilyMaG helps guitarists enter notes using a virtual fretboard. Each click generates a snippet of LilyPond code, which you can copy into a LilyPond source file to create a guitar score.

LilyPond is a music engraving program that produces high-quality sheet music from text-based notation.

What LilyMaG can (and cannot) do

LilyMaG is a note-entry aid, not a complete graphical score editor. Clicking notes on the fretboard does not automatically produce a finished score. To use it effectively, you will need some basic knowledge of LilyPond and its notation.

The advantage is flexibility: LilyMaG can help you enter notes quickly, while LilyPond lets you refine the resulting score using its full range of engraving features.

Try LilyMaG

Open the LilyMaG application and click a few positions on the fretboard. Watch the generated LilyPond code appear in the editor.

The project repository on GitHub contains the source files. To download them, click the green Code button and choose Download ZIP.

Using LilyMaG online or offline

You can use LilyMaG online or download it to run locally without an internet connection. The application needs just three files, kept together in the same folder:

  • index.html — the main application page
  • lilymag.css — the visual styling
  • lilymag.js — the application logic

The optional help files are in the help folder.

To run LilyMaG offline, double-click index.html to open it in your browser. No installation is required.

Getting started

1. Create a basic LilyPond score

If you do not already have a LilyPond source file, LilyMaG can generate a starting template.

  1. On the toolbar, open the Insert drop-down menu (second from the left).
  2. Choose LilyPond (second from the bottom). A basic LilyPond source file appears in the editor.
  3. Click To Clipboard (fourth from the left), then paste the code into your preferred text editor.
  4. Remove or comment out any parts you do not need. In LilyPond, a percent sign (%) starts a comment.
  5. Find the comment % your score goes here. You will replace it with the notes you generate.
  6. Return to LilyMaG and click Clear (fifth from the left) to prepare for note entry.

2. Enter notes on the fretboard

Click a position on the virtual fretboard. LilyMaG adds the corresponding LilyPond note code to the editor.

Colored dots mark the three most recently selected notes:

  • Black — the most recent note
  • Orange (terracotta) — the previous note
  • Green (celadon) — the note before that

Try clicking several positions to see how the code and fretboard display change.

3. Add durations, fingerings, and other details

By default, clicking the fretboard enters the note and its string number. To add information such as note duration, left- or right-hand fingering, or dynamics, use the controls in the lower-left part of the application.

Normally, select these options before clicking the note. If you forgot to do so, select the desired options and click Change Last Note to apply them to the most recently entered note.

4. Enter chords

To enter a chord, select the Chord checkbox before entering its first note. Click all the notes belonging to the chord, then deselect Chord when you have finished.

5. Copy the notes and generate a PDF

Click To Clipboard and paste the generated note code into your LilyPond source file, replacing the % your score goes here comment. Save the file, then compile it with LilyPond to produce a PDF score.

LilyPond must be installed on your computer to compile the source file. LilyMaG itself does not generate PDFs.

Sharps and flats

Some pitches can be written in two enharmonically equivalent ways, such as F-sharp (F♯) and G-flat (G♭). Use the Sharp/Flat switch on the toolbar to choose which spelling LilyMaG generates.

For example, LilyPond writes F-sharp as fis and G-flat as ges.

Toolbar controls

  • New Bar — inserts code for a new measure, including a bar check. It supports one or two voices; using one voice is simpler when starting out.
  • Insert — inserts LilyPond code for musical features such as rests, ties, and slurs. Hover over an option to see its tooltip.
  • Change Last Note — applies the currently selected note options to the most recently entered note rather than the next one.
  • Chord — enables or ends chord entry.
  • Triplet — enables triplet entry.
  • Number of Frets — changes the number of frets shown on the virtual fretboard.
  • Sharp/Flat — selects the spelling of enharmonic notes (for example, cis or des).
  • To Clipboard — copies the editor contents so you can paste them into another text editor.
  • Clear — clears the editor and resets the fretboard for a new passage.

Suggested workflow

  1. Generate a basic LilyPond template, if needed, and paste it into your text editor.
  2. Use the fretboard and note-entry controls to build a passage in LilyMaG.
  3. Click To Clipboard and paste the generated code into the LilyPond source file.
  4. Repeat as needed, refining the notation in your text editor.
  5. Compile the source file with LilyPond to produce your sheet music.

LilyMaG makes note entry easier; LilyPond handles the full score and its engraving.

For more information about LilyPond, visit lilypond.org.
