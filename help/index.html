LilyMaG Help

LilyPond Maker for Guitar

What is LilyMaG?

LilyMaG stands for LilyPond Maker for Guitar.

LilyMaG is a simple tool that helps guitarists create music notation using a virtual fretboard. By clicking on the fretboard, you can generate snippets of LilyPond code that can be copied into a LilyPond source file and used to produce guitar scores.

LilyPond is a powerful music engraving program that produces high-quality sheet music from text-based notation.

What LilyMaG can (and cannot) do

LilyMaG is a note-entry aid, not a complete graphical score editor. Clicking notes on the fretboard does not automatically produce a finished score. You will need at least a basic understanding of LilyPond and its notation.

The advantage of this approach is flexibility. You can use LilyMaG to generate a quick, simple score and then refine it directly in LilyPond. You are not limited by LilyMaG's features, but only by what LilyPond can do and your knowledge of how to use it.

Using LilyMaG online or offline

You can use LilyMaG directly in your web browser or download it and run it locally, without an internet connection.

The application consists of just three files:

You can use LilyMaG in your browser online or download it for offline use. Keep these files together in one folder:

  • index.html - the main application page
  • lilymag.css - the visual styling
  • lilymag.js - the application logic

Help files are in help folder. They are optional.

To use LilyMaG offline, download the files into the same folder on your computer and double-click index.html to open it in your browser. No installation is required.

Getting started

Click a position on the virtual fretboard. Each click adds the corresponding LilyPond note code to the editor in the lower-right part of the application.

Colored dots show your three most recently selected notes:

  • Black — most recent note
  • Orange (Terracotta) — previous note
  • Green (Celadon) — note before that

Try clicking several fretboard positions and watch the editor update.

Understanding the generated code

The generated notation identifies the note and the guitar string on which it was selected. The string number follows a slash in the displayed notation.

You can paste the result into a LilyPond source file, then adjust it and add the remaining musical details as needed.

Sharps and flats

Some pitches have two names, such as F-sharp (F♯) and G-flat (G♭). Use the sharp/flat switch on the toolbar to choose how these notes are written.

For example, LilyPond writes F-sharp as fis and G-flat as ges.

Toolbar commands

  • To Clipboard: Copies the editor contents so you can paste them into your preferred text editor.
  • Clear: Clears the editor and resets the fretboard, ready for a new passage.

Suggested workflow

  1. Click notes on the virtual fretboard (play around to see what LilyMaG can do).
  2. Click To Clipboard.
  3. Paste the code into your LilyPond source file.
  4. Compile the LilyPond file to produce your sheet music.

LilyMaG helps with note entry; LilyPond provides the full range of music engraving features.

For more information about LilyPond, visit lilypond.org.
