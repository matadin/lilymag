Lilypond Maker for Guitar help page.

LilyMaG is Lilypond Maker for Guitar. It is tool for helping to create guitar scores by clicking on virtual frettboard. It creates lilypond (music engraving program) code snippets, which can be coppied and pasted into lilypond code, from wich guitar scores can be created. To be used effectively, at least minimal knowledge of lilypond program and its code is necessary. Downside of using LilyMaG is that you must have at least minmal knowledge of using lilypond program, it is not so that you can only click on virtual frettboard and make guitar score automatically (allthough LilyMaG tool can help a lot). Upside is that you are in no way limited by capabilities of LilyMaG tool. You can use it to create quick and dirty scores, and then you can refine that score at will, limited only by the capabilities of the (very powerfull) lilypond music engraving program, and your knowledge of it's capabilities.

You can use LilyMaG tool online, if it is simpler for you, or you can download it to your computer, and use it offline. It consists of only three files (html, css and js file, this help beeing fourth file). Put it somewhere on your computer, doubleclick on html file, and use it at your will.

Let's click on virtual frettboard. Each click creates lilypond code for that note in the editor (down left). Last pressed note in big black dot on frettboard, note pressed before is orange, and note pressed before is green dot. Just try it out. Name of the note, slash, number of string on which note was played. By clicking on sharp/flat switcher or toolbar on toolbar, we can change wheather not is e.g. F# or Gb Fis or Ges. By clicking on "to clipboard" button on the toolbar, we copy contents of the editor into clipboard, so we can copy it into our editor of choice. By clicking on "clear" button on the toolbar, we clear contens of the editor (and virtual frettboard), and we can start creating new snippet.
